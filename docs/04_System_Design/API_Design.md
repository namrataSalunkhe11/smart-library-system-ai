# API Design

## Smart Library System with AI Recommendations

---

# 1. Introduction

## 1.1 Purpose

The purpose of this document is to define the API structure used for communication between the frontend application, backend server, database, and AI recommendation service.

The API layer provides secure and organized access to system functionalities.

---

## 1.2 API Architecture

The system follows a RESTful API architecture.

Communication flow:

```text id="h7p3m9"
Frontend Application

        |

        ↓

REST API Endpoints

        |

        ↓

Backend Application Server

        |

        ↓

Database / AI Service
```

---

# 2. API Technology

The Smart Library System uses:

| Component              | Technology        |
| ---------------------- | ----------------- |
| API Style              | REST API          |
| Backend Framework      | Flask / FastAPI   |
| Data Format            | JSON              |
| Authentication         | JWT Token         |
| Database Communication | ORM / SQL Queries |

---

# 3. API Security

## Authentication

The system uses JWT-based authentication.

Authentication flow:

```text id="q9m4v6"
User Login

    ↓

Credential Verification

    ↓

JWT Token Generation

    ↓

Token Sent With Requests

    ↓

Authorized API Access
```

---

## Authorization

Access is controlled using user roles:

| Role          | Permission                                     |
| ------------- | ---------------------------------------------- |
| Student       | Search, Reserve, View History, Recommendations |
| Librarian     | Manage Books, Issue/Return, Fine Management    |
| Administrator | User Management, Reports                       |

---

# 5. API Endpoint Specifications

---

# 5.1 Authentication APIs

## Register User

**Endpoint**

```text
POST /api/auth/register
```

**Description**

Creates a new user account.

**Request Body**

```json
{
    "name": "User Name",
    "email": "user@example.com",
    "password": "password",
    "role": "student"
}
```

**Response**

```json
{
    "status": "success",
    "message": "User registered successfully"
}
```

---

## Login User

**Endpoint**

```text
POST /api/auth/login
```

**Description**

Authenticates user and generates JWT token.

**Response**

```json
{
    "token": "jwt_token",
    "role": "student"
}
```

# 6. API Module Summary

The API layer is divided into multiple modules based on system functionality.

---

## Authentication Module

Responsible for:

* User registration
* User login
* Token generation
* User authentication

---

## User Management Module

Responsible for:

* Creating users
* Updating user information
* Managing user roles
* Account control

---

## Book Management Module

Responsible for:

* Adding books
* Updating book details
* Searching books
* Managing catalogue information

---

## Reservation Module

Responsible for:

* Creating reservations
* Tracking reservation status
* Managing reserved books

---

## Transaction Module

Responsible for:

* Issuing books
* Returning books
* Maintaining borrowing records

---

## Fine Management Module

Responsible for:

* Calculating fines
* Tracking fine status
* Maintaining fine history

---

## AI Recommendation Module

Responsible for:

* Processing user activity data
* Analyzing book information
* Generating personalized recommendations

---

## Reporting Module

Responsible for:

* Dashboard statistics
* Library activity reports
* Data analysis

---
