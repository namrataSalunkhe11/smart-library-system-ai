# 1. Purpose

This handbook defines the development standards, coding conventions, documentation guidelines, Git workflow, and quality practices that will be followed throughout the development of the Smart Library System with AI Recommendations.

The objective is to ensure consistency, maintainability, and professionalism across the entire project.

---

# 2. Development Methodology

The project will follow the Agile Software Development Life Cycle (SDLC), where the system will be developed in small, incremental phases. Each phase will include planning, implementation, testing, documentation, and review.

---

# 3. Technology Stack

| Layer | Technology |
|--------|------------|
| Frontend | React.js (Vite) |
| Backend | Python Flask |
| Database | MySQL 8 |
| ORM | SQLAlchemy |
| Authentication | JWT |
| AI | scikit-learn, Pandas, NumPy |
| Version Control | Git & GitHub |
| Documentation | Markdown |

---

# 4. Repository Structure

The repository will be organized into dedicated folders for frontend, backend, database, documentation, assets, and supporting scripts to ensure a clean and maintainable project structure.

---

# 5. Documentation Policy

- Documentation will be maintained alongside development.
- Every major implementation will have corresponding documentation.
- Documents will use version numbers.
- All documentation will be stored in the `docs` directory.
